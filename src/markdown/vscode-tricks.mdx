If you're working in software development, VS Code is your best friend that you spend hours with every day. But are you using it to its full potential? You might feel everything is fine - "I can get my work done on time, why do I need to learn new tricks?"

What I'll show you in this article will boost your productivity with small tricks that can save you time and effort in the long run. These are not advanced features, but simple tips that can give you more time to enjoy your coffee.

### Searching

Before we dive into searching tricks, let me share a preference tip. It may depend on your personal preference, but I find it better to have the search panel in the center of the screen rather than at the default position on top.

First, press `Cmd + P` and let's move the search panel to the center.

1. **Search by Symbol**: If you're looking for a specific function or variable, you can use the `#` symbol followed by the name to search for symbols.

<MdxImage src="/blog/vscode-tricks_1.png" alt="vscode-tricks_1" />

2. **Search by Line Number**: If you want to search for a specific line of code, you can use the `:` symbol followed by the line number.

<MdxImage src="/blog/vscode-tricks_2.png" alt="vscode-tricks_2" />

3. **Tab switching between files**: If you have multiple files open, you can quickly switch between them using `Cmd + Tab` to cycle through the open tabs.

<MdxImage src="/blog/vscode-tricks_3.jpg" alt="vscode-tricks_3" />

### Text Manipulation

1. **Edit same text together**: If you want to edit the same text all at once, you can use the `Cmd + D` shortcut to select the next occurrence of the selected text. This allows you to make changes to all instances simultaneously.

<MdxImage src="/blog/vscode-tricks_4.png" alt="vscode-tricks_4" />

2. **Edit with multiple cursors**: If you want to add cursors at multiple locations, you can hold down the `Option` key (or `Alt` on Windows) and click at the desired locations to place multiple cursors.

<MdxImage src="/blog/vscode-tricks_5.png" alt="vscode-tricks_5" />

3. **Move lines up and down**: If you want to move a line of code up or down, you can use `Option + Up/Down Arrow` (or `Alt + Up/Down Arrow` on Windows) to quickly reposition the line without cutting and pasting.

<MdxImage src="/blog/vscode-tricks_6.jpg" alt="vscode-tricks_6" />

Actually, there are many more tricks beyond these. But these are the ones I use the most in my daily work. I hope you find them useful and that they help you become more productive in your coding journey!
